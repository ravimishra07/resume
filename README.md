Edit `resume.tex`. GitHub Actions builds and commits the updated PDF after each source change. The workflow can also be run manually from the Actions tab.

To compile locally with XeLaTeX:

```sh
xelatex -interaction=nonstopmode -halt-on-error -jobname=Ravi-Mishra-Resume resume.tex
```
